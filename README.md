# Real-Time Anomaly Detection with Kafka and Ollama

This project implements a real-time anomaly detection system using Kafka for message streaming and Ollama for generating embeddings. The system processes log messages and detects anomalies based on the embeddings generated from the logs.

## Features
- Real-time log processing using Kafka.
- Anomaly detection based on embeddings generated by the Ollama model.
- Dockerized application for easy deployment.

## Requirements
- Docker
- Docker Compose

## Setup
1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd <repository-directory>
   ```

2. Ensure you have the required files:
   - `docker-compose.yml`
   - `Dockerfile`
   - `requirements.txt`
   - `kafka_producer.py`
   - `kafka_consumer.py`
   - `faiss_store.py`
   - `config.py`
   - `entrypoint.sh`
   - Any other necessary files.

3. Make sure the Ollama model is downloaded and available in the `ollama` directory.

## Running the Application
1. Build and start the Docker containers:
   ```bash
   docker-compose up --build -d
   ```

2. Wait for the services to initialize (especially the Ollama model).

3. Run the test script to start the producer and consumer:
   ```bash
   ./run_test.sh
   ```

4. Monitor the logs to see the output of the anomaly detection:
   ```bash
   docker logs -f kafka_consumer
   ```
